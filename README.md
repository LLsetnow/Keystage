# Keystage · 客制化机械键盘定制与展示工坊

基于 Three.js + Canvas2D 的 3D 客制化机械键盘定制、实时预览与渲染导出 Demo。无需构建工具，浏览器直接打开即可运行。

## 核心功能

- **多款键盘配列与模型切换**：支持 `60% (61键)`、`65% (68键)`、`75% (82键 + 金属旋钮)`、`80% TKL (87键)` 与 `100% 全尺寸 (104键)`，可单独查看任意一款键盘并支持实体键盘敲击联动与程序化机械轴音效。
- **逐键查看与深度定制**：
  - 点击任意键帽选中（支持 `Shift` 多选或按字母区/大键/点缀键/方向键批量选择），支持一键**单键特写**拉近检视细节。
  - **文字显隐与刻字位置**：逐键或全局切换**显示/隐藏文字（无刻）**、**正刻（键帽顶部）**与**侧刻（键帽前侧斜面）**，支持自定义主/副字符与字号缩放。
  - **键帽贴图与配色**：支持自定义键帽底色/字符色、6 种内置程序化纹理（纯色哑光、碳纤维、大理石纹、赛博渐变、浮世绘浪、像素格纹），以及**上传本地图片作为键帽贴图**（支持缩放与旋转调节）。
- **整机外观与预设场景光照**：
  - 内置 6 套整机配色方案与 4 种套件外壳材质（阳极氧化铝、磨砂半透 PC、北美黑胡桃木、陶瓷烤漆），支持 RGB 背光与桌垫开关。
  - 内置 5 套影棚光照预设（柔光摄影棚、暖调日落桌面、赛博霓虹暗室、冷调极简画廊、暗夜戏剧聚光），支持曝光、主光角度与环境反射微调。
- **总览图导出与运镜视频录制**：
  - 一键导出 **1080P / 2K / 4K 高清 PNG 总览图**，可选当前视角、45° 英雄展台、标准俯视或低角度侧刻视角，支持右下角规格水印。
  - 内置 4 套影棚运镜预设（360° 环绕、俯仰开场秀、键帽微距扫镜、正/侧刻双视角巡航）及**自定义关键帧轨道**，支持实时预览、伴随波浪按键动画，并一键录制导出 **60fps 高清 WebM 演示视频**。

## 运行方式

1. **直接打开**：双击 `index.html` 用现代浏览器（Chrome / Edge / Safari）打开即可体验。
2. **本地服务（推荐）**：
   ```bash
   python3 -m http.server 8080
   ```
   然后访问 `http://localhost:8080`。
